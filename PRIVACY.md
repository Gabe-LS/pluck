# Privacy Policy — Pluck

**Last updated:** September 2026

## Data Collection

Pluck does **not** collect, store, transmit, or share any personal data or browsing activity.

## What the extension accesses

The extension operates exclusively within the DevTools Elements panel sidebar. It reads:

- **DOM structure and computed CSS** — of the element you select, to extract and inline styles.

This information is used only to generate the copied output locally. It is never sent to any server, analytics service, or third party.

## Permissions

| Permission | Why |
|---|---|
| `clipboardWrite` | Write extracted HTML or Markdown to your clipboard |

## Third-party libraries

The extension bundles three open-source libraries that run entirely locally:

| Library | Purpose | License |
|---|---|---|
| [Prism.js](https://prismjs.com/) | Syntax highlighting in the preview panel | MIT |
| [Turndown](https://github.com/mixmark-io/turndown) | HTML to Markdown conversion | MIT |
| [Marked](https://github.com/markedjs/marked) | Markdown rendering in the preview panel | MIT |

None of these libraries make network requests or collect data.

## Third parties

The extension does not communicate with any external server. It does not include analytics, telemetry, or tracking of any kind.
